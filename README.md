# Portfolio – Zineb FANDI

Portfolio personnel bilingue (FR / EN) présentant mon profil de **Data Scientist** :
Machine Learning, IA explicable (XAI), NLP, LLM & RAG.

🔗 **En ligne :** [fandizineb.github.io](https://fandizineb.github.io)

## Aperçu

Site statique, responsive, avec bascule de langue français / anglais.
Sections : profil, expériences, projets, publications & communication scientifique,
certifications, CV et contact.

## Structure du projet

```
.
├── index.html          # Structure de la page (contenu)
├── css/
│   └── styles.css      # Styles (design, mise en page, responsive)
├── js/
│   └── i18n.js         # Traductions FR / EN et bascule de langue
└── CV_Zineb_FANDI.pdf  # CV téléchargeable
```

Le code est organisé selon la **séparation des responsabilités** :
la structure (HTML), le style (CSS) et le comportement (JavaScript) sont
dans des fichiers distincts.

## Technologies

- HTML5 / CSS3 (Flexbox, Grid, variables CSS, responsive)
- JavaScript (vanilla) pour l'internationalisation FR / EN
- Google Fonts (DM Sans, DM Serif Display)
- Hébergement : GitHub Pages

## Lancer en local

Aucune dépendance à installer. Ouvrir `index.html` dans un navigateur,
ou servir le dossier avec un petit serveur local :

```bash
python3 -m http.server 8000
# puis ouvrir http://localhost:8000
```
